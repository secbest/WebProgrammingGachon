The 5 steps

  1. Create a GitHub account you Your username appears to be secbest (it is the owner of this course repo), so you already have one. Use a professional username.
  2. Create a new Public repository named webpro-w9 you On github.com click New repository, name it exactly webpro-w9, choose Public, and do not tick "Add a README".
  3. Local folder, git init, index.html with your name and date, commit, push done locally The page is ready at webpro-w9/index.html. Copy that file into a new folder on your computer and run: 
    mkdir webpro-w9 && cd webpro-w9
git init -b main
# copy index.html into this folder, then:
git add index.html
git commit -m "Add index.html with student name and date for Week 9 homework"
git remote add origin https://github.com/secbest/webpro-w9.git
git push -u origin main
  4. Enable GitHub Pages you Repo → Settings → Pages → Deploy from a branch → main → / (root) → Save. Wait about a minute. Your site will be at https://secbest.github.io/webpro-w9/.
  5. Submit on the LMS you Paste both URLs: 
    https://github.com/secbest/webpro-w9
https://secbest.github.io/webpro-w9/
    Open the Pages URL in a private window first to confirm it loads.
