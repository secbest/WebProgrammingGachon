# Interactive Shopping Cart

Week 11 React State homework (K0126002 Web Programming), kept in the Week 12 folder.

1. Product list: 5 items with name, price and image URL (`src/components/products.js`)
2. Add / Remove buttons: cart state is an array of `{ id, qty }` (`ShoppingCart.jsx`, `ProductList.jsx`)
3. Cart sidebar: items and a total price computed from state (`CartPanel.jsx`)
4. Quantity controls: + and - per item (`CartPanel.jsx`)
5. `ShoppingCart` component: product list + cart panel (`ShoppingCart.jsx`)

The same cart is also a "Shop" section in the school portfolio: https://secbest.github.io/portfolio/

## Run it

```
npm install
npm run dev
```
